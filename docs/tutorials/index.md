# 📚 Tutorials

Combine features to build something useful. Each tutorial includes setup and a way to check the result.

## [Announce AFK changes](/tutorials/afk-announcements)

Combine Stored Commands and Events to broadcast when a player goes AFK or returns.

## [Award a Builder group](/tutorials/builder-award)

Combine permissions, playtime and group automation for a one-hour milestone.

## [Create a VIP destination](/tutorials/vip-area)

Combine a realm warp and permission groups to restrict a shared destination.

## [Build a shared team base](/tutorials/team-base)

Combine a team, claim rules and shared destinations for a settlement.

## [Build an information NPC](/tutorials/information-npc)

Combine an NPC and a custom form into a simple help desk.

## [Build a kill leaderboard](/tutorials/kill-leaderboard)

Combine a filtered stat, placeholder and managed scoreboard.

## [Create a random supply crate](/tutorials/loot-crate)

Combine a weighted loot table and a free crate with a per-player cooldown.
