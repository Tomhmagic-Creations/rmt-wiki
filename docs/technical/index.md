# 🛠️ Technical features

Set up each feature on its own, with practical steps rather than implementation details.

## [Stored Commands](/technical/stored-commands)

Save one named sequence, then run it directly or attach it to another feature.

## [Events](/technical/events)

Run a saved action when a chosen event happens and its conditions match.

## [Placeholders](/technical/placeholders)

Insert names, stats and other changing values into supported text and actions.

## [Custom Forms](/technical/custom-forms)

Create a readable menu with text and buttons that open forms or run Stored Commands.

## [Stats](/technical/stats)

Track a gameplay total and make it available to profiles, displays and automation.

## [Scoreboards](/technical/scoreboards)

Display numeric placeholders or copies of existing objectives in Minecraft scoreboard areas.

## [Group automation](/technical/group-automation)

Award groups or run configured actions when a player meets a milestone.

## [Metadata](/technical/metadata)

Save named world or player values for displays and automation.

## [Custom Loot](/technical/custom-loot)

Build a weighted loot table and deliver its generated items.

## [Holograms](/technical/holograms)

Place floating text and optionally add click or hit actions.

## [NPCs](/technical/npcs)

Place characters, customise their appearance and attach useful interactions.

## [Portals](/technical/portals)

Select an entry area that runs actions or sends players to Spawn or RTP.

## [Block Commands](/technical/block-commands)

Turn a selected block into a protected click or hit action.

## [Utility commands](/technical/utility-commands)

Use small command tools for item editing, entities, effects and experience.

## [Error Log](/technical/error-log)

Find broken configuration references and fix the saved setup that caused them.
