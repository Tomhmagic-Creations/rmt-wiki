# 📋 Personal-setting permissions

Exact nodes and descriptions for realm administrators configuring this area.

## thm_rmt:profile.settings.teleport.tpa

**Incoming TPA Preferences**

Choose who can ask to teleport to you. Does not grant teleport access. Use profile.settings.* for all personal settings.

Data Type | Scope
--- | ---
allow/deny | global
