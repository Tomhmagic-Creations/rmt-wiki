# 📖 Start using RMT

Set up your world, open the menu, and find the tools you need.


## 📌 Activate the addon

1. Activate both the RMT **behaviour pack** and **resource pack** for your world.
2. Open the world and let RMT finish its first setup.
3. Use the **Realm Tool**, or enter `/thm_rmt:menu` in chat.
4. Choose a feature from the menu. Buttons depend on your permissions and the realm's configuration.

The realm can give you a Realm Tool automatically on your first join. If you need one later, use `/thm_rmt:tool` (short name `/tool` when available). This needs `thm_rmt:command.tool` and space in your inventory. It does not duplicate a tool you already carry. The Realm Tool no longer has a crafting recipe.

Use the current V2 packs together. A resource pack on its own cannot provide the management features.

## 📌 If you are a player

Start with [Profile](/players/profile), [Travel](/players/travel) and [Claims](/claims/getting-started). The **Guide** in the RMT menu also has searchable help while you play. If a button is missing, ask the realm's administrator whether you have access.

## ⌨️ Commands in this wiki

Examples use the full `/thm_rmt:` namespace to avoid conflicts with Minecraft or other addons. In a command block or a Stored Command, omit the leading slash. Quote names and messages containing spaces.

A command permission, a feature permission and the right to target other players can be separate requirements. See the [command reference](/reference/commands) when building automation.
