# 📖 Finding your way

Learn the menu layout and the terms used throughout this wiki.


| Area | What you do there |
| --- | --- |
| Main menu | Travel, homes, warps, claims, teams, kits, waypoints and your profile |
| Profile | Personal settings, statistics, mail and your own displays |
| Moderation | Handle players, reports, inventories and action history |
| Admin | Configure realm policy, permissions, destinations, rewards and presentation |
| Technical | Create commands, events, forms, NPC interactions, portals and dynamic displays |

**Favourites** lets you save shortcuts to entries you can access. Search for an entry and add it, then reorder or remove shortcuts as needed. A shortcut still checks your current permissions. Addon-provided shortcuts may last only for the session.

**Guide** opens the in-game help library. Browse a category or search for the feature's name.

## 📌 Common terms

| Term | Meaning |
| --- | --- |
| Chunk | A 16 × 16 block area, extending vertically through the world |
| Claim | Protected land owned by a player or the realm |
| Subclaim | Part of a claim with its own trust list and rules |
| Claim Allowance | The amount of land you can claim, measured in chunks |
| Group | A collection of permissions assigned to players |
| Permission node | An identifier controlling one ability or limit |
| Placeholder | Text such as `%thm_rmt:player_name%` that is replaced with a value |
| Stored Command | A named sequence of commands that another feature can run |
| Event binding | A saved rule that runs Stored Commands when an event and its conditions match |
| ID | The stable identifier used by commands and linked features; it can differ from a display name |

## 📌 Warm-up or cooldown?

A **warm-up** is the wait before a teleport happens. A **cooldown** is the wait before a feature can be used again. The default ordinary teleport warm-up is five seconds, but your realm can change it through permissions.
