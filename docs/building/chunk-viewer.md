# 🧱 Chunk and claim outlines

See chunk boundaries and nearby protected land without holding a special item.


## 📌 Show your current chunk

1. Open **Profile > Personal Settings > Chunk Viewer**.
2. Enable it, or use the permitted `/thm_rmt:chunks` command.
3. Move between chunks to see the current boundary update.

Outlines are private to you. The old Chunk Viewer item is no longer needed, and the feature does not occupy the action bar.

## 📌 Show nearby claims

Enable **Claim Borders** in the same Personal Settings area. These particles help distinguish protected land from the current chunk outline. The preference starts off and affects only your own display.

The realm can restrict access to either setting. Border rendering depends on dimension, distance and the feature's display limits; an outline is a visual aid, not the authority for whether an action is protected.

See [Claims](/claims/getting-started) before selecting land.
