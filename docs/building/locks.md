# 🧱 Locks

Lock supported containers and doors, then share access with trusted players.


1. Get the **Lock** item.
2. Interact with a supported container or door to use its locking workflow.
3. Use the lock's management controls to add or remove trusted players.

The lock owner manages the trusted list. Trusted players can interact with and break the locked block, so trust only players who should have that access. Staff with the relevant bypass may unlock it.

## 🔐 Lock access and claim access

A lock does not override a claim or global interaction rule. A player may need access through both the lock and the surrounding land. The Realm Tool does not bypass a locked container.

## 💡 Share a chest without sharing a base

Give your friend the intended claim interaction access and add them to that chest lock’s trusted list. Test with your friend’s account. If either layer denies access, the chest can remain closed. Trusted lock users can also break the locked block, so do not use a lock trust list as read-only access.

## ❓ If a block cannot be locked

The realm chooses supported lockable block types. Ask staff whether the specific type is supported. For doors and beds, the feature resolves the relevant source part; nearby chests are not automatically treated as one detected lock just because they touch.
