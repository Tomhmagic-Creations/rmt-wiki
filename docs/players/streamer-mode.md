# 🧭 Streamer Mode

Mask sensitive information in supported RMT screens while sharing your game.


1. Open **Profile > Personal Settings > Streamer Mode**.
2. Enable the master switch.
3. Choose which protections to apply: menu coordinates, message coordinates, player IDs, mail and waypoint markers.

The master starts off; individual protections start on. Turning off the master remembers your choices for next time.

Protected values in supported displays become `***`. Hidden mail still arrives, with generic unread notifications. Waypoint privacy hides RMT markers without deleting or unpinning them.

::: info Check your whole screen
Streamer Mode covers supported RMT output. Vanilla coordinates, manually typed text, world scenery, holograms and other addons can still reveal information. It does not change permissions, saved locations or the values used by commands.
:::
