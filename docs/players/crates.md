# 📦 Open a crate

Use a configured reward block with the correct payment and enough room for its reward.


## 📌 Open once

1. Read the crate's name and cost.
2. Bring the requested key, items or scoreboard balance.
3. Interact once with the assigned block.
4. Check the result before opening again. Holding use does not repeatedly open it.

## 🔑 Payment types

| Type | What you need |
| --- | --- |
| Key | A genuine key issued for that crate |
| Item | The specified ordinary item type and quantity |
| Score | Enough points in its configured objective |
| Nothing | No payment, though access and limits still apply |

A renamed lookalike is not an authenticated key. Payment items are taken from inventory/hotbar, not equipment or offhand. A genuine key is not spent accidentally as an ordinary Item payment.

## ⏳ Limits apply to the definition

Several blocks may open the same crate. Your cooldown and lifetime opening count are shared across those blocks, rather than resetting when you try another copy. A lifetime limit is different from a cooldown.

## ❓ If payment happens but a reward fails

An accepted opening can commit payment and count before a reward reports a configuration error. Keep the crate name and the error message and ask staff to investigate. Repeated opening can spend more payment; it is not an automatic recovery process. Make room before collecting rewards, and inspect any overflow near the block.
