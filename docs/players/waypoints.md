# 🧭 Waypoints

Find places with locator-bar markers without teleporting.


Open **Waypoints** or run `/thm_rmt:waypoint` (alias `wp`). A waypoint is a navigation marker, not a warp.

## 📌 Make a personal marker

1. Open the personal waypoint management options.
2. Add a marker and set its name, dimension and coordinates.
3. Choose an icon, colour and display range.
4. Enable and save it.
5. Pin it when you want it prioritised, or hide it just for yourself.

Personal, team and realm markers have similar display controls. Team owners/admins manage team markers. Realm markers are managed by staff; you can view them when permitted.

## 📌 Understand the markers

| Marker | Behaviour |
| --- | --- |
| Spawn | Uses normal spawn, never the first-join destination |
| Latest death | Clears permanently when you return within three blocks of it after respawning |
| Claim | Follows the claim and its permitted audience |
| Custom | Personal, team or realm-owned saved location |
| Addon-provided | Available while the supplying addon has registered it |

Hidden markers keep their definitions. A disabled marker is hidden from its audience but remains in its management list. Zero maximum distance means unlimited range.

## ❓ If a marker is missing

Check the dimension, distance limits, enabled state, Waypoints access and Streamer Mode. The locator bar has a capacity: pinned markers take priority, followed by higher priority and nearer markers. Ask staff to check display diagnostics if your marker settings appear correct.
