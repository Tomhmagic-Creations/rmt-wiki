# 🛍️ Use the Realm Store

Browse the realm catalogue, check the cost and keep a receipt for your purchase.


## 📌 Buy a product

1. Open the Realm Store button when shown, or use `/thm_rmt:store` if permitted.
2. Choose a category and product.
3. Read its description and selected payment type.
4. Complete the payment workflow and inspect the result.
5. Open **My Purchases** to check the receipt.

The main-menu button appears only when the owner enables it and your account can use the store. A hidden button is not proof that the command is disabled; ask staff how the realm exposes it.

## 💳 Payment

Products may require ordinary inventory items, points from a scoreboard objective or an externally issued redemption code. Use a code only for the intended product. The public product page does not expose the owner's private token configuration.

## ❓ Missing products

A disabled category hides its products. A product can be unavailable because the store is closed, access is missing or its setup is incomplete. Changing payment or offering products is a staff task, not a personal preference.

## 🧾 Check the receipt before retrying

If an error or interruption occurs, inspect My Purchases and what you already received. Keep the product ID/name and status for staff. A message that a command was scheduled is not proof the eventual reward completed, and retrying a purchase can create another charge.
