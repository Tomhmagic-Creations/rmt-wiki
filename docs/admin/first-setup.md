# ⚙️ First realm setup

Prepare the realm policy and staff access before inviting ordinary players.


1. Activate both current V2 packs and open the world as a Minecraft operator.
2. Open **Admin > Permissions** and review Default, Moderator and Admin.
3. Assign staff explicitly through Player Permissions. Nobody becomes staff merely by joining.
4. Review realm settings, spawn, claim protection and the player feature limits.
5. Test with an ordinary non-operator account before opening the realm.

## 🔐 Operator or Admin?

Minecraft operator status normally bypasses RMT permission checks. An RMT Admin group grants its configured addon powers but does not make its members native operators. Some native-operator-only rules remain separate, such as exclusions from saved inventory snapshots.

## 📌 Change defaults deliberately

Every player implicitly belongs to Default. Keep ordinary abilities there and put staff powers in staff groups. Initial setup is not repeated on every V2 restart: removing a grant or deleting a staff group is not automatically undone.

Home limits, teleport delays, RTP limits and many other feature controls are permissions rather than realm-setting switches. Use the dedicated permission guides and catalogue in the Admin dropdown instead of granting a broad wildcard.

## ✅ Verify a role

Try the menu, a home, a claim, a shared warp and a moderation action using the intended account. A missing button may be a permission restriction, not missing addon functionality. An operator passing a test does not establish that an ordinary player can do the same thing.
