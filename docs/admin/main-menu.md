# ⚙️ Edit Main Menu

Change the text players see at the top of the RMT menu.


1. Open **Admin > Edit Main Menu**.
2. Add, edit, delete or reorder body-text lines.
3. Use supported placeholders where useful and check their player context.
4. Save and open the main menu as an ordinary player to review it.

Clearing the text restores the default introduction. This changes the menu body, not the built-in button order or a banner. Lines cannot contain embedded line breaks. The maximum is 200 lines and 30,000 UTF-8 bytes in total.

If another administrator changes the text while you are editing, reopen it and review their version rather than overwriting it with a stale draft.
