# ⚙️ Invsee and saved inventories

Inspect live player items and optionally manage eligible offline logout snapshots.


1. Open **Moderation > Invsee** or use `/thm_rmt:invsee`.
2. Select an online player, or an offline player with an eligible saved inventory.
3. Choose Inventory, Hotbar, Equipment or Ender Chest according to your access.
4. Open a slot to inspect its details. Edit, take and clear only when separately authorised.

| Section | Contents |
| --- | --- |
| Inventory | 27 main slots |
| Hotbar | Nine hotbar slots |
| Equipment | Live armour, main hand and offhand; offline main hand is represented by the hotbar |
| Ender Chest | 27 native Ender Chest slots |

Taking an item requires room in the moderator's inventory. **Clear All** covers main inventory, hotbar and equipment; the Ender Chest has its own operation.

## ❓ If an offline inventory is unavailable

The realm owner must have enabled eligible logout snapshots before capture. A player without a valid snapshot is unavailable, not an empty inventory. Native operators are excluded. Reopen a view if the target joins, leaves or a saved revision changes.
